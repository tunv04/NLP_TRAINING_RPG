# Mô tả code: VietnameseTextProcessor

## Tổng quan

File này xây dựng class `VietnameseTextProcessor` dùng để tiền xử lý văn bản tiếng Việt trước khi đưa vào các bài toán NLP.

Processor hỗ trợ các thao tác chính:

- Tách câu tiếng Việt.
- Tách từ tiếng Việt bằng thư viện `underthesea`.
- Xóa thẻ HTML.
- Xóa URL.
- Xóa emoji.
- Chuyển văn bản thành chữ thường.
- Xóa dấu câu.
- Chuẩn hóa khoảng trắng, tab và ký tự xuống dòng.
- Load danh sách stopwords từ file `.txt`.
- Xóa stopwords khỏi danh sách token nếu tùy chọn này được bật.
- Trả về cả danh sách token và văn bản đã xử lý cuối cùng.

## Thư viện sử dụng

```python
import re
import string
from underthesea import sent_tokenize, word_tokenize
```

- `re`: dùng để xử lý chuỗi bằng regular expression, ví dụ xóa URL, HTML, emoji và chuẩn hóa khoảng trắng.
- `string`: dùng để lấy danh sách dấu câu chuẩn trong Python.
- `underthesea`: thư viện NLP cho tiếng Việt, được dùng để tách câu và tách từ.

## Class `VietnameseTextProcessor`

Class này gom toàn bộ các bước xử lý văn bản tiếng Việt vào một nơi.

Khi khởi tạo, class nhận hai tham số:

```python
def __init__(self, stopword_file=None, remove_stopwords_option=True)
```

- `stopword_file`: đường dẫn tới file chứa danh sách stopwords.
- `remove_stopwords_option`: nếu là `True`, processor sẽ xóa stopwords sau khi tách từ.

Nếu có truyền `stopword_file`, chương trình sẽ tự động load stopwords từ file đó.

## Các hàm chính

### `load_stopwords(file_path)`

Hàm này đọc danh sách stopwords từ file `.txt`.

Mỗi dòng trong file được xem là một stopword. Từ được chuyển về chữ thường rồi thêm vào `self.stopwords`.

Nếu file không tồn tại, chương trình sẽ in ra thông báo:

```text
Không tìm thấy file stopwords: <file_path>
```

### `sentence_tokenize(text)`

Hàm này tách văn bản thành các câu.

Trước khi tách câu, văn bản được:

1. Xóa thẻ HTML.
2. Chuẩn hóa khoảng trắng.
3. Tách câu bằng `sent_tokenize()` của `underthesea`.

### `word_tokenize(text)`

Hàm này tách từ tiếng Việt bằng `underthesea`.

```python
return word_tokenize(text, format="text").split()
```

Với tiếng Việt, một từ có thể gồm nhiều âm tiết. `underthesea` có thể nối các âm tiết thuộc cùng một từ bằng dấu gạch dưới.

Ví dụ:

```text
xử lý ngôn ngữ tự nhiên
```

có thể được tách thành:

```python
["xử_lý", "ngôn_ngữ", "tự_nhiên"]
```

### `lowercase(text)`

Chuyển toàn bộ văn bản thành chữ thường.

Ví dụ:

```text
Việt Nam Đẹp
```

thành:

```text
việt nam đẹp
```

### `remove_urls(text)`

Xóa URL khỏi văn bản.

Regex được sử dụng:

```python
r"http\S+|https\S+|www\S+"
```

Hàm này xử lý các URL bắt đầu bằng:

- `http`
- `https`
- `www`

### `remove_html(text)`

Xóa các thẻ HTML khỏi văn bản.

Ví dụ:

```html
<p>Hello!!!</p>
```

thành:

```text
 Hello!!! 
```

### `remove_emojis(text)`

Xóa emoji khỏi văn bản bằng regex theo các vùng Unicode phổ biến của emoji.

Ví dụ:

```text
I am learning NLP 😄
```

thành:

```text
I am learning NLP
```

### `remove_punctuation(text)`

Xóa dấu câu khỏi văn bản.

Hàm này kết hợp:

- `string.punctuation`: dấu câu tiếng Anh như `.`, `,`, `!`, `?`, `:`, `;`.
- `vietnamese_punctuation`: một số dấu câu thường gặp trong văn bản tiếng Việt như `“”‘’…–—«»`.

### `normalize_whitespace(text)`

Chuẩn hóa khoảng trắng bằng regex:

```python
re.sub(r"\s+", " ", text).strip()
```

Hàm này giúp:

- Gộp nhiều khoảng trắng thành một khoảng trắng.
- Chuyển tab và xuống dòng thành khoảng trắng.
- Xóa khoảng trắng thừa ở đầu và cuối chuỗi.

### `remove_stopwords(tokens)`

Xóa stopwords khỏi danh sách token.

Nếu `remove_stopwords_option=False`, hàm sẽ trả về danh sách token ban đầu.

Nếu tùy chọn này là `True`, hàm sẽ giữ lại những token không nằm trong `self.stopwords`.

## Pipeline `preprocess(text)`

Đây là hàm xử lý hoàn chỉnh của class.

Các bước thực hiện:

1. Xóa HTML.
2. Xóa URL.
3. Xóa emoji.
4. Chuyển văn bản thành chữ thường.
5. Xóa dấu câu.
6. Chuẩn hóa khoảng trắng.
7. Tách từ tiếng Việt.
8. Xóa stopwords nếu được bật.
9. Ghép tokens thành văn bản cuối cùng.

Kết quả trả về là một dictionary:

```python
{
    "tokens": tokens,
    "processed_text": final_text
}
```

Trong đó:

- `tokens`: danh sách token sau xử lý.
- `processed_text`: chuỗi văn bản đã xử lý cuối cùng.

## Phần chạy thử

Trong khối:

```python
if __name__ == "__main__":
```

Code tạo một đoạn văn bản mẫu có:

- HTML.
- Tiếng Anh.
- Emoji.
- URL.
- Dấu câu.
- Văn bản tiếng Việt.

Sau đó chương trình:

1. Khởi tạo `VietnameseTextProcessor`.
2. Load stopwords từ file `vietnamese_stopwords.txt`.
3. Tách câu bằng `sentence_tokenize()`.
4. Tiền xử lý toàn bộ văn bản bằng `preprocess()`.
5. In ra danh sách câu, danh sách token và văn bản cuối cùng.

## Ví dụ kết quả mong đợi

Với input có dạng:

```text
<p>Hello!!!</p>
I am learning NLP 😄
Visit https://abc.com now!!!

Tôi đang học xử lý ngôn ngữ tự nhiên.
Việt Nam là một đất nước rất đẹp.
```

Sau khi xử lý, các phần như HTML, URL, emoji và dấu câu sẽ bị loại bỏ.

Văn bản tiếng Việt sẽ được tách từ bằng `underthesea`, ví dụ:

```python
["tôi", "đang", "học", "xử_lý", "ngôn_ngữ", "tự_nhiên", ...]
```

Nếu các từ như `tôi`, `đang`, `là`, `một` nằm trong file stopwords, chúng có thể bị loại bỏ khỏi kết quả cuối cùng.
