Ở bước này, ta tập trung vào Database + Search Service + FastAPI API.
Mini_pj/
├── app/
│   ├── main.py                    # Khởi tạo FastAPI app
│   ├── core/config.py             # Đọc config từ .env
│   ├── db/session.py              # SQLAlchemy engine/session
│   ├── models/product.py          # Product, Comment ORM models
│   ├── schemas/product.py         # Pydantic response schemas
│   ├── repositories/
│   │   └── product_repository.py  # Query DB, upsert sản phẩm
│   ├── services/
│   │   ├── text_normalizer.py     # Bỏ dấu, normalize text
│   │   └── search_service.py      # Basic + fuzzy search
│   └── api/v1/
│       ├── router.py
│       └── product_routes.py      # API endpoints
├── scripts/
│   ├── create_tables.py           # Tạo bảng DB
│   └── import_products.py         # Import JSON vào DB
├── data/
│   └── chiaki_products.json       # Dữ liệu sản phẩm
├── craw.py                        # Script crawl từ Chiaki.vn
├── test_search.py                 # Test search trực tiếp qua service
├── test_api.py                    # Test API qua requests
├── README.md
├── QUICK_START.py
└── requirements.txt
